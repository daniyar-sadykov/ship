# /ship для Claude Code

Одна команда, которая доводит начатую работу до влитого `main`: прогоняет
проверки, коммитит остаток, открывает пулреквест, вливает его squash и
убирает ветку. Если GitHub CLI не настроен, вливает локально и говорит об
этом.

## Установка

В открытой сессии Claude Code выполнить одну команду:

```
/plugin install ship --marketplace daniyar-sadykov/ship
```

Так работает на Claude Code 2.1.275 и новее. Версию посмотреть в терминале:
`claude --version`. Версия старее, тогда две команды подряд:

```
/plugin marketplace add daniyar-sadykov/ship
```

```
/plugin install ship@ship
```

Проверить, что встало: набрать `/` и найти в списке `ship`. Или `/plugin`,
раздел с установленными.

## Как пользоваться

Закончил работу в проекте, набрал:

```
/ship
```

Коммита ещё нет и хочется подсказать, о чём работа:

```
/ship починил расчёт скидки в корзине
```

Дальше агент всё делает сам и в конце отчитывается одной строкой: что
влито и ссылка на пулреквест. Остановится и спросит только в четырёх
случаях: проверки упали непонятно почему, в дереве чужая незакоммиченная
работа, конфликт при влитии, `main` закрыт на запись.

## Что нужно, чтобы работало

Обязательно:

- `git` и проект, который уже является git-репозиторием.

Необязательно, но тогда будет пулреквест вместо локального влития:

- GitHub CLI: установить с https://cli.github.com, потом `gh auth login`.
- Ремоут `origin`, указывающий на твой репозиторий на GitHub.

Нет `gh` или нет ремоута, команда не падает: она вливает ветку в `main`
локально через `merge --squash` и пишет в отчёте, почему пулреквеста не
было.

## Чего команда не сделает

- Не запушит force в `main`.
- Не перепишет историю: ни `rebase` чужих коммитов, ни `amend` отправленного.
- Не удалит и не поправит тест, чтобы прогон стал зелёным.
- Не закоммитит `.env`, ключи и токены. Нашла такое в изменениях,
  останавливается и говорит.

## Обновить

```
/plugin marketplace update ship
```

## Поставить без маркетплейса

Склонировать репозиторий и запустить Claude Code с каталогом плагина:

```bash
git clone https://github.com/daniyar-sadykov/ship.git
claude --plugin-dir ./ship/plugins/ship
```

Либо скопировать файл `plugins/ship/commands/ship.md` в `~/.claude/commands/`.
Тогда команда `/ship` появится во всех проектах без плагина.
